# 数据负责人验收清单

- [ ] 公司编码与组织路径唯一、有效，权限范围与推广批次一致。
- [ ] 税率、可弥补以前年度亏损和前三完整年度平均税负率线下表已批准并留存版本摘要。
- [ ] SAP 利润表、分红、所得税计提、其他应付款暂估、工资薪金、福利费和公益性捐赠明细期间完整。
- [ ] 合思无票报销、业务招待费报销及 OA 业务招待、自采报销、物料领用流程范围完整。
- [ ] 收到分红采用 SAP 账上收到分红金额，潜在调增金额采用暂估余额加无票报销金额。
- [ ] 源记录数、金额、币种、公司、年度和期间已与源系统对账。
- [ ] 缺失来源或主数据时公司被阻断，未输出“无风险”或虚假输出就绪时间。
- [ ] 已发布快照不可修改；更正通过新快照集完成并保留前后摘要。
- [ ] 代表公司重跑使用稳定幂等键，风险指纹、证据任务和有效金额无重复。
- [ ] 数据异常、修复、重送、发布和重跑均有不可变审计引用。
