# 用户培训手册

## 角色和边界

集团税务查看集团范围、复核和关闭风险；事业部税务只读授权组织子树；公司财务处理本公司风险和登记改账凭证；数据管理员维护来源和导入主数据但不能形成税务结论；审计人员只读分配范围。未授权资源统一不可见。

## 日常操作

季度查看所得税计提差异、累计税负率偏离和潜在调增税务成本。月度查看业务招待费、福利费和公益性捐赠疑似错入明细。每条结果应核对公司、期间、原始来源、快照、规则/模型版本、证据引用、风险金额和改账建议。

公司财务处理风险时记录事实依据和调整凭证；集团税务在证据充分后复核或关闭。模型低置信度、证据不足或供应商失败进入技术/人工复核，不得直接标记为安全。

## 导出和隐私

导出任务使用创建时冻结的权限范围，并在下载时重新检查当前权限。权限撤销、制品过期或跨公司请求不会返回下载地址。不得复制完整自由文本、个人信息、附件或凭据到工单、聊天和日志。

## 异常上报

数据缺失联系数据负责人并按数据源失败手册处理；模型超时或无效响应联系运维和安全负责人；跨公司访问、签名异常或重复风险立即停止操作并升级为安全/回滚事件。记录批次、公司、期间、稳定错误码和请求/任务 ID，不粘贴敏感正文。

## 培训确认

培训需覆盖权限边界、公式含义、证据复核、风险处理、改账建议、导出安全、异常升级和回滚沟通。参训人完成代表公司演练后，由所在公司财务负责人和集团税务负责人确认。
