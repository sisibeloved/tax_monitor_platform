# 模型供应商失败处置手册

## 告警信号

供应商超时、限流、无效结构化响应、保留策略不合规、工作负载身份失败或模型网关连续重试耗尽时触发。提示词注入、越权证据请求或模式变更请求按安全事件处理。

## 处置原则

- 保留规则筛出的候选项和证据任务，标记为技术复核，不得标记为安全。
- 模型不能获得数据库句柄、自由 SQL 或未列入允许清单的工具。
- 不向日志、指标或审计写入完整自由文本、个人信息或供应商凭据。
- 只对可重试技术错误执行有界退避；策略、主数据或结构错误不自动重试。

## 恢复步骤

1. 运维负责人暂停受影响模型队列并保留其他公式监测。
2. 安全负责人确认供应商零留存、禁止公开训练和凭据状态。
3. 检查模型网关错误码、版本、请求摘要、延迟和重试次数。
4. 供应商恢复后以冻结证据引用重放，不重新扩大公司或字段范围。
5. 对照金标集确认生产召回率不低于 95%、高置信度准确率不低于 80%、已知案例零漏检。
6. 只重跑失败公司和期间，验证稳定幂等键与风险指纹。

持续失败或新模型配置不兼容时，按 `rollback.md` 切换到上一份已验证清单。恢复证明包含供应商事件号、批准人、重放报告、受影响批次、重跑结果和审计引用。
