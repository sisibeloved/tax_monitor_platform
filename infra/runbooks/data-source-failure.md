# 数据源失败处置手册

## 告警信号

数据源成员缺失、文件模式不符、期间不连续、公司主数据未批准、对账差异或数据就绪超过约定时间时触发。数据异常、技术失败和税务风险必须分别展示。

## 责任与批准

数据负责人负责定位源系统和重送数据；公司财务确认本公司账务期间与金额；集团税务负责人决定是否延后批次。不得由运维人员绕过质量门禁。涉及覆盖已发布快照时需数据负责人和集团税务负责人共同批准。

## 遏制与恢复

1. 在运维驾驶舱确认批次、公司、期间、缺失来源和稳定错误码。
2. 停止该公司后续监测，不影响其他有效公司。
3. 将问题记录为数据异常；不得生成“无风险”结果或虚假的输出就绪时间。
4. 修复源文件或接口后重新摄取，以原始文件摘要和批次 ID 对账。
5. 发布新的完整快照集；不得修改已发布快照。
6. 只重跑受影响公司，核对幂等键、检测数量、金额和风险指纹。

## 一致性检查和沟通

比较源记录数、成功/失败数、总金额、公司/期间范围和快照成员摘要。向公司财务、数据负责人和集团税务负责人同步预计恢复时间。恢复证明包括新快照集 ID、对账结果、重跑任务 ID、输出就绪时间和审计事件引用。
